GitHub Pages 上傳方式

1. 解壓縮此資料夾。
2. 將全部檔案上傳到同一個 GitHub repository。
3. 確認首頁檔名為 index.html。
4. 到 GitHub -> Settings -> Pages。
5. Source 選 Deploy from a branch。
6. Branch 選 main / root。
7. 儲存後等待網址產生。

檔案說明
- index.html：總首頁
- group01-05.html ~ group36-40.html：大單元頁
- unit01.html ~ unit40.html：各小單元頁
- data.js：全部單字資料
- app.js：學習/考試/發音/寶箱邏輯
- styles.css：版面樣式

使用提醒
- iPhone / iPad 第一次進入時，先按「啟用語音」，再按「測試聲音」。
- 若外部字典音檔抓不到，系統會自動改用裝置內建英文朗讀。
